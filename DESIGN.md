# Design System: Quantum Use Case Zoo

## 1. Overview

**Creative North Star: "The Lab Notebook"**

A working scientist's notebook, not a glossy report. The surface is warm parchment, the ink is real ink, and the verdicts read like a researcher's own marginalia — stamped, dated, sourced. The personality lives in restraint and precision, not in gradients or motion: a calm, plain-spoken authority that's earned, with just enough warmth and idiosyncrasy that it reads as written by a sharp human scientist rather than generated by a template.

The system explicitly rejects glossy quantum-startup marketing (gradient/particle backgrounds, qubit-sphere animations, breathless "quantum advantage" claims) and generic SaaS landing pages (oversized heroes, stock illustration, gradient blobs, marketing-fluff copy) in equal measure. It also rejects the opposite failure mode — a flat, personality-free academic template — by keeping one bold, deliberate gesture: the verdict tiles, rendered as solid warm-ink color blocks that lift slightly on hover, the single moment of "delight" the system allows itself.

**Key Characteristics:**

- Warm, paper-toned neutrals carry the page; one saturated rust ink does the brand work
- Flat by default; depth is earned only through interaction (hover), never decorative
- Verdicts are color-coded like rubber stamps — fixed colors, not theme-reactive, because a verdict's meaning shouldn't shift with light/dark mode
- Generous whitespace; the tile grid is the hero, everything else (header, filters) is deliberately compact so it clears out of the way

## 2. Colors

A warm, ink-and-paper palette built in OKLCH for perceptual consistency, then converted to sRGB hex. One primary accent carries the brand; verdict badges are fixed, mode-independent "stamp" colors.

### Primary

- **Cinnabar Ink** (`#b53e20` light / `#c94c2d` dark): the single brand accent. Used on use-case tiles (solid fill), active filter pills, the use-case header's left-border accent, and inline links. Brightens slightly in dark mode to stay vivid against the dark background — the only color in the system that shifts with theme mode.

### Secondary

- **Verdigris Moss** (`#5a6c28` light / `#7c9048` dark): a muted olive used sparingly for secondary accents and the rare incidental link, distinct from Cinnabar Ink in both hue and role.

### Tertiary (verdict stamps — fixed, not theme-reactive)

- **Sage Stamp** (`#7c9048`): "Sensing-led" verdict badge. Paired with deep-ink text, not white — olive at a readable lightness fails contrast with white.
- **Amber Stamp** (`#c26f00`): "Premature" verdict badge. Also paired with deep-ink text for the same reason.
- **Neutral Stamp** (`#6b7280`): "Fault-tolerant era only" verdict badge — deliberately the one true neutral (desaturated, non-warm) color in the system, paired with white text. Its colorlessness is the point: this verdict means "no opinion yet, hardware doesn't exist."

### Neutral

- **Parchment** (`#faf4ec` light / `#130b07` dark): page background. Warm-tinted on purpose — see the Tinted Surface Rule below.
- **Parchment Border** (`#e3d9ce` light / `#352c25` dark): dividers, card borders, pill borders.
- **Stone** (`#8b7d73` light / `#837870` dark): muted/secondary text (filter labels, metadata).
- **Walnut** (`#574a42` light / `#d1c9c0` dark): body text.
- **Deep Ink** (`#221812` light / `#f4ede4` dark): headings, the darkest/lightest extreme of the neutral ramp.

### Named Rules

**The Tinted Surface Rule.** The background is warm parchment, not pure white/black, because the mood is explicitly environmental — a notebook page, not a SaaS app shell. This is the one place a "feels warm" mood is allowed to leak into the surface itself, because the surface IS the metaphor.

**The Fixed Stamp Rule.** Verdict badge colors (`Sage`, `Amber`, `Neutral Stamp`) never change with light/dark mode. A verdict is a fact about the world, not a UI preference — it shouldn't visually drift when someone toggles dark mode.

## 3. Typography

**Display/Heading Font:** Fraunces (with Georgia, serif fallback) — applies to every `h1`–`h6` site-wide, including tile titles and use-case note headers.
**Body Font:** Work Sans (with system sans-serif fallback)
**Label/Mono Font:** JetBrains Mono

**Character:** A warm, slightly idiosyncratic soft-serif (Fraunces) carries every heading — the one typeface choice doing real personality work, deliberately contrasted against the clean, no-nonsense Work Sans body copy. This is the typographic equivalent of "rigor with a pulse": headlines get a little character, the dense technical body text stays maximally legible. JetBrains Mono appears only for code blocks and small uppercase labels (filter categories, verdict badge text), giving those moments a quiet "instrument readout" feel against the warm body copy.

### Hierarchy

- **Display** (Fraunces, 700, 1.9rem, line-height 1.2): the home page H1 only. Deliberately restrained in size (not a 3+ rem hero) — the tiles, not the headline, are the page's main feature.
- **Title** (Fraunces, 600, 1.4–1.8rem): tile titles, use-case note headers.
- **Body** (Work Sans, 400, 1rem, line-height 1.55, max ~42ch on the thesis paragraph): all running text.
- **Label** (600, 0.7–0.78rem, uppercase, letter-spacing 0.03–0.04em, JetBrains Mono or Work Sans): filter pill text, verdict badges, metadata field labels.

### Named Rules

**The Quiet Headline Rule.** Display type never exceeds ~2rem on the home page. A loud hero headline competes with the tile grid for "main feature" status; the headline's job is to get out of the way fast.

**The One Serif Rule.** Fraunces is reserved for headings only — never body copy, labels, or UI chrome. One typeface carries all the personality, so it doesn't dilute into "two competing fonts" territory.

## 4. Elevation

Flat by default, everywhere. There are no resting shadows on cards, pills, or the use-case header box — flatness is part of the calm, paper-like character. The single exception is the use-case tile on hover: it lifts (`translateY(-6px)`) on a slight springy overshoot easing, gains a soft ambient shadow, and its verdict badge tilts a couple of degrees like a rubber stamp being pressed. This is the system's one deliberate "delight" moment — and its only literal motion-as-metaphor gesture — reserved for the page's hero component so it doesn't get diluted across every surface. All hover/press motion respects `prefers-reduced-motion`.

### Shadow Vocabulary

- **Tile hover lift** (`box-shadow: 0 16px 32px rgba(0, 0, 0, 0.18)`, paired with `transform: translateY(-6px)` on `cubic-bezier(0.34, 1.56, 0.64, 1)`): the only shadow in the system. Signals "this is the clickable, important thing" — used nowhere else.
- **Badge stamp-tilt** (`transform: rotate(-2deg) scale(1.06)` on the same overshoot easing, triggered by `.tile:hover`): the verdict badge tilts like it's just been pressed onto the page. The system's one literal nod to the "stamp" metaphor.
- **Pill press** (`transform: scale(0.96)` on `:active`): tiny tactile feedback on filter pill clicks, not a hover effect.

### Named Rules

**The Flat-Until-Touched Rule.** Every surface is flat at rest. Depth appears only as a direct response to hover/interaction on the tile component — never as ambient decoration on cards, boxes, or panels.

## 5. Components

### Use-Case Tiles (signature component)

The page's main feature — large, bold, solid-color blocks, not bordered outline cards.

- **Shape:** generous corner radius (`1rem`), `min-height: 210px`, `padding: 1.75rem`.
- **Fill:** solid Cinnabar Ink (`var(--secondary)`, theme-reactive). White text throughout (title + metadata) — translucent/opacity-reduced white is forbidden here because it drops below WCAG AA against the fill (see Do's and Don'ts).
- **Content:** a small uppercase verdict badge top-left, a title (1.4rem, semibold), one compact metadata line (sector · timeline, joined, not stacked across multiple lines).
- **Hover:** lifts and gains shadow (see Elevation). This is the only animated element on the page.
- **Grid:** `repeat(auto-fill, minmax(300px, 1fr))`, `gap: 1.75rem` — wide tiles, generous gaps, never a dense mosaic.

### Filter Pills

- **Style:** pill-shaped (`border-radius: 999px`), 1px parchment-border outline, parchment background at rest.
- **Active state:** filled solid Cinnabar Ink, parchment-colored text.
- **Hover:** border shifts to Cinnabar Ink; no fill change until active.
- **Grouping:** three small rows (Sector / Timeline / Verdict), each with a small uppercase muted-stone label. Kept deliberately compact (small font, tight gaps) — filters are a utility bar above the hero, not a competing visual block.

### Verdict Badges

- **Style:** small uppercase pill-corner rectangle (`border-radius: 0.35rem`), fixed "stamp" fill color per verdict (see Colors), never theme-reactive.
- **Text color:** dark ink on Sage/Amber, white on Neutral Stamp — chosen per-color for contrast, not a single rule.

### Use-Case Header Box (note pages)

- **Style:** parchment-border background, 4px solid left border in Cinnabar Ink, generously padded, rounded corners (`0.5rem`).
- **Content:** title, then a horizontal row of metadata fields (sector / timeline / confidence) with small uppercase muted labels, plus the verdict badge pushed to the far right.

## 6. Do's and Don'ts

### Do:

- **Do** keep the home page header compact (display type ≤ 2rem) — the tile grid is the main feature, not the headline.
- **Do** use solid, opaque white text on use-case tiles. Translucent white (e.g. `rgba(255,255,255,0.85)`) drops below WCAG AA against the Cinnabar Ink fill.
- **Do** keep verdict badge colors fixed across light/dark mode — they're facts, not theme preferences.
- **Do** use dark ink text on Sage and Amber badges, white text on Neutral Stamp — match text color to the specific fill, not a single default.
- **Do** leave every surface flat at rest; reserve shadow/lift for the use-case tile hover state only.

### Don't:

- **Don't** add gradient or particle backgrounds, qubit-sphere animations, or breathless "quantum advantage" copy — the glossy quantum-startup-marketing look this site explicitly exists to push back against.
- **Don't** add oversized hero sections, stock illustration, gradient blobs, or marketing-fluff copy — the generic-SaaS-landing-page look is just as much an anti-reference as the quantum-hype look.
- **Don't** crowd the landing page. If a new section competes with the tile grid for attention, cut it or push it below a clear divider (see `.usecase-home-extra`).
- **Don't** introduce a second accent hue for "just one more thing" — Cinnabar Ink carries the brand alone; Verdigris Moss and the verdict stamps are reserved for their specific semantic roles, not general decoration.
- **Don't** apply resting shadows to cards, pills, or boxes — flatness is the baseline; only the tile hover state gets depth.
